## 🎯 Perché questo corso è diverso?

Dimentica le nozioni noiose imparate a memoria. Qui imparerai **facendo**, come in un videogioco:

- 🧱 **Livello 1:** Installiamo il nostro arsenale di strumenti
- ⚡ **Livello 2:** Scriviamo il primo codice PHP (spoiler: è più facile di quanto pensi)
- 🌐 **Livello 3:** Lanciamo Laragon e vediamo il nostro sito andare **live** in localhost
- 📝 **Livello 4:** Creiamo veri form che parlano con l'utente
- 🗄️ **Livello 5:** Connettiamo tutto a un database MySQL come dei veri professionisti

> [!TIP]
> Ogni modulo ha una **Missione Finale** 🎮: un boss da sconfiggere prima di passare al livello successivo. Puoi fare livello difficile? Sempre.

## 📜 Regole di Ingaggio (come si consegna)

1. **Forka** questa repository sul tuo account GitHub (pulsante in alto a destra, non aver paura).
2. Per ogni modulo, apri la cartella e leggi il `README.md` **prima** di toccare il codice. Davvero. Leggilo.
3. Risolvi gli esercizi nel file `esercizi.php` di ogni modulo, **senza guardare le soluzioni** finché non hai provato almeno 3 volte.
4. Committa con messaggi chiari, es: `modulo-01: completata missione 3`.
5. Consegna aprendo una **Pull Request** verso la repository del docente.

### 🆘 Hai un dubbio? Segnala un bug?

Apri una **Issue**! Descrivi il problema come se stessi scrivendo a un amico:
- 📍 Dove sei bloccato (file e riga)
- 🧪 Cosa hai provato
- 💥 Messaggio di errore esatto (copia-incolla, niente "non funziona")

> [!NOTE]
> Nessuna domanda è stupida. La domanda stupida è quella che non fai e che ti blocca per 3 ore davanti al monitor. 💀
